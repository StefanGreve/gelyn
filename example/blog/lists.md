# Lists

A task list renders a disabled checkbox per item:

- [x] Written
- [x] Dated
- [ ] Linked from anywhere by hand

Numbering takes a style from the marker it opens with, so `a.` and `i.` carry across to the published list:

a. Lettered
a. And lower case

i. Numbered
i. In roman

## Definitions

A definition list wants its text to start at the fourth column, which is the one rule worth remembering here:

Front matter
:   The YAML block a document opens with.

Draft
:   A document that declares no date, and that no table lists.
